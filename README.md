# LocalAI Calc

**[localaicalc.xyz](https://localaicalc.xyz)** — Website that shows which local AI models your hardware can run with estimated tokens/sec.

---

## What it does

- Enter RAM, VRAM, CPU, GPU and storage — or pick a preset device
- Shows every model as ✅ runs / ⚠️ marginal / ❌ too heavy
- Estimates tok/s based on GPU memory bandwidth and model size
